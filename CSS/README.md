# Carpeta CSS

Aquí se guardan los archivos finales de estilos que usa la página.

## Qué va aquí

- `style.css`: hoja de estilos principal del proyecto
- `style.css.map`: mapa de origen para depuración

## Uso

Este archivo es el que el navegador carga desde `index.html`.

Si quieres dejar la carpeta más limpia, puedes conservar solo `style.css` y borrar el `.map` si no lo vas a usar.
