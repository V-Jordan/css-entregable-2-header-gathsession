# Carpeta JS

Aquí se guarda la lógica JavaScript del proyecto.

## Qué va aquí

- `app.js`: archivo principal de interacción y comportamiento
- `vendor/`: librerías o scripts de terceros

## Uso

Se suele enlazar desde `index.html` para activar efectos, menús, animaciones o comportamiento dinámico.

Mantén aquí solo lo necesario para no mezclar scripts de prueba con código del proyecto final.
